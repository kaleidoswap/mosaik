Mosaik

The order is the coin.

A covenant DEX on the Liquid Network. Every order is a Tessera — a single coin whose Simplicity covenant enforces the trade itself.
No exchange. No matching engine. No maker server. No custody. The coin rejects any spend that doesn't honour its terms — so a swap is trustless by construction, not by promise.
Liquid Network Simplicity covenants Nostr orderbook non-custodial on-chain enforced

01 The idea

A maker wants to sell asset A for asset B. Instead of posting an order to an exchange that might not honour it, they lock asset A into one Liquid coin governed by a covenant.

On Mosaik, an order isn't a promise a market maker might break — it's a covenant the coin itself keeps.

That single UTXO is the offer. It is permissionless (anyone can fill it, the maker need not be online), uncheatable (the taker cannot take asset A without paying asset B — the coin refuses), atomic (one transaction moves both assets or neither confirms), and needs no infrastructure at all.

02 A Tessera — two doors, no keys

The covenant is keyless: pure transaction introspection, no signatures anywhere. A coin reads the transaction trying to spend it and allows it only through one of two doors.

SETTLE — fill the offer
Spendable by anyone, if the spending transaction has an output paying exactly amount_b of asset_b to the maker. The taker keeps asset A; the maker is paid. One atomic swap.
REFUND — reclaim the offer (keyless)
After block height timeout, spendable by anyone — but only by a transaction that returns the locked asset to the maker. No key, no signature. The maker can stay offline forever; a griefer can only pay the network fee to hand the maker their coin back.

Four terms — asset id, amount, maker script, timeout — are committed into the Taproot tapleaf, so they cannot change once the offer is funded. There is no maker public key: the maker is just an address.

04 Why this needs Simplicity

The whole construction rests on transaction introspection — a coin reading the outputs of the transaction spending it, and checking amounts, assets and scripts. Bitcoin Script cannot do this. LiquiDEX-style swaps get atomicity from a SIGHASH trick; adaptor-signature PTLCs work on plain Taproot. A covenant that enforces the counter-payment itself is the thing that genuinely requires Simplicity — and Mosaik runs it on-chain, validated by a Simplicity-capable elementsd.

05 Built & demoable

Not a slide deck — a working covenant DEX, enforced on a live Elements regtest.

  • The covenant compiles to a Commitment Merkle Root and is execution- tested — SETTLE and the keyless REFUND.
  • Enforced on-chain — a Simplicity-capable node executes the covenant and rejects any spend that underpays the maker.
  • Multi-asset swaps — L-BTC/asset, asset/L-BTC and asset/asset, in either direction. The covenant never inspects the locked asset.
  • Keyless reclaim — the maker recovers an unfilled offer after the timeout with no key and no signature.
  • Nostr orderbook — offers are published and discovered over Nostr; no server, no account.
  • Browser wallet — a two-wallet maker/taker UI: fund, make offers, swap, inspect the live covenant.
  • Partial fills — sweep a grid of covenant UTXOs in one tx (roadmap).
⚔ Attack the covenant — the demo's centrepiece

The wallet UI ships deliberate cheating fills. Each builds a well-formed, balanced transaction the mempool would accept — and the covenant rejects every one:

  • Underpay the maker — pay one unit short → rejected.
  • Pay the wrong address — redirect the maker's output → rejected.
  • Hide the maker output — move it off index 0 → rejected.

Watching the coin stop a thief — not just turn for an honest fill — is what makes the covenant's value visceral.

06 The stack

tessera

The covenant

The Tessera covenant in SimplicityHL, parameterised and compiled to a CMR; Taproot address derivation; witness assembly.

mosaik-core

Offers & settlement

Offer types, multi-asset Elements transaction construction, the SETTLE and keyless REFUND builders, the Elements RPC client.

mosaik-relay

The Nostr orderbook

Offers published as addressable Nostr events; browse and discover with no server in the path.

mosaik-cli + webapp

CLI & wallet UI

The mosaik command and a single-file browser wallet — fund, make, take, reclaim, and inspect the covenant live.
